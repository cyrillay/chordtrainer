# V13 — Guitar refinement + configurable accent + desktop zoom

## Guitar
- Display polish on the fretboard: cleaner spacing, sharper inlays, refined dot / mute markers

## Metronome
- **Configurable accent** — pick which beat carries the accent (1, 2, 3, 4, or none). Replaces the previous fixed downbeat behavior. Setting is persisted.

## Layout
- Desktop zoom decreased — the layout now occupies less width so the chord display, instrument view, and controls stay close together on wide monitors

## Fixes
- Presets correctly drive the circle of fifths (root selection state was getting out of sync after switching presets)
- Minor UX fixes across the settings panel
