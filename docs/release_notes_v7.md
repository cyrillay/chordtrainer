# V7 — Rewards system + UI polish

## What's new
- **Rewards / streak counter** — playing chords correctly in a row builds a streak that surfaces a tier label ("warming up", "in the zone", …) and a subtle visual cue under the chord display
- New site favicon
- Streak state persists in memory across the session and resets on a missed chord

## UX
- Stage layout tightened around the chord display
- Generator + views streamlined to feed the rewards module without extra event wiring
