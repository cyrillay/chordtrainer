# V6 — Custom progressions mode

## What's new
- **Custom progressions manager** (`progressionManager.js`): users can create, edit, and delete their own roman-numeral progressions, persisted alongside the bundled library
- Add / remove / rename progressions in a dedicated modal accessible from the progressions section
- Custom progressions stream into the same generator pipeline as the built-in ones

## Fixes
- Various minor bugs across the progression UI and generator
